# Monitor de Red

Monitor de red simple, funcional, y sin efectos visuales innecesarios.

## Características

- Ping a dispositivos en background (no bloquea la UI)
- Histórico de 30 días en SQLite
- Detección de caídas y latencia alta
- Chat con Altair (bot de consultas)
- Export a Excel/CSV
- Autenticación por contraseña
- WebSocket para cambios de estado en vivo
